## 🧭 About me

- 🎓 Public-administration grad → fintech **operations** day job → taught myself to build, starting **2022**
- 🤖 Today: **AI Agent engineer & enterprise AI-native consultant** — FDE-style, embedded in real workflows, shipping agents that survive production
- 🪞 I build **verifiable mirror infrastructure** at **[agentsmirror.com](https://agentsmirror.com)** (**1.90M+ installer downloads served**) so developers behind network barriers get official tooling — the walls I hit became roads for others（为下一个 builder 拆掉我撞过的墙）
  - **[codexapp.agentsmirror.com](https://codexapp.agentsmirror.com)** — Official OpenAI Codex Desktop DMG / MSIX mirror, Sparkle delta feed, [Codex App Manager](https://github.com/Wangnov/Codex-App-Manager) & 50 `.codexskin` themes
  - **[claudeapp.agentsmirror.com](https://claudeapp.agentsmirror.com)** — Official Anthropic Claude Desktop offline DMG / Windows MSIX / Linux deb mirror (`SHA256` verified)
  - **[uv.agentsmirror.com](https://github.com/Wangnov/uv-custom)** — High-speed Mainland China mirror for Astral `uv`, `python-build-standalone` runtimes & PyPI Simple metadata
- 🛠 Agent tooling ecosystem for **Claude Code / Codex / OpenClaw**: CLIs, skills, statuslines, WeChat bridges
- ✍️ I write & speak in Chinese dev communities · reach me via **[agentsmirror.com](https://agentsmirror.com/#about)** or GitHub Issues

> 🎯 **2026 focus** — porting my agent tooling to **AWS Bedrock + AgentCore** and documenting every step in Chinese, so the next self-taught builder ships faster than I did. re:Invent 2026 — see you there? 🎲
